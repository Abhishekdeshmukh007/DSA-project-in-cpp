# RescueLoop — Program Output

## 1. Overview

RescueLoop is a Disaster Rescue Coordination Simulator developed using C++. It demonstrates rescue-team management and emergency incident tracking using linked-list data structures.

## 2. Main Menu

The main menu allows users to select different operations, including rescue-team management, incident reporting, viewing teams, viewing incident history, and exiting the program.

## 3. Rescue Team Management

This module allows users to register rescue teams and manage their availability. The circular linked list supports continuous traversal of registered teams.

## 4. Emergency Incident Reporting

Users can enter emergency incident details and assign a priority level. The system records the incident and searches for an available rescue team.

## 5. Rescue Team Allocation

If a team is available, it can be assigned to the incident and its status updated. If no team is available, the incident can remain pending.

## 6. Incident History

The doubly linked list stores incident records and supports traversal of the incident history in forward and backward directions.

## 7. Output Screenshots

Screenshots of the program execution are provided separately to demonstrate the implemented features and their results.

## 8. Conclusion

The program output demonstrates how linked-list data structures can be used to organize rescue teams and maintain emergency incident records. The results depend on the functionality implemented in the source code.
